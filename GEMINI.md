# Project Rules

## Zero Emojis Policy
- Do not ever use emojis anywhere in this project.
- This includes all source code (`.ts`, `.js`), templates/views (`.html`, `.ejs`, etc.), styling, documentation (`.md`), logs, test suites, and commit messages.
- Always use standard text tags like `[INFO]`, `[WARN]`, `[ERROR]`, `[SUCCESS]`, `[TEST]`, `[PASS]`, `[FAIL]`, or FontAwesome icon tags in frontend HTML.
